# Changelog

All notable changes to `ofxGgmlCore` should be documented here.

This project follows the addon-family baseline tags used across the ofxGgml ecosystem.

## Unreleased

### Added

- Codex and GitHub guidance for agent-assisted development.
- Addon hygiene workflow and issue/PR templates.

### Changed

- Updated the default official ggml runtime pin from `v0.13.1` to
  `v0.19.0`.
- Removed the ACE-Step-specific ggml fork mode and readiness fields. Core now
  remains an official, model-neutral ggml provider; the fork is owned by
  `ofxGgmlMusic`.

- Nothing yet.
